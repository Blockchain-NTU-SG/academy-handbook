# Upstream attribution

`academy-handbook` began as a fork of the
[ETHPanda / LXDAO Web3 Internship Handbook](https://github.com/ethpanda-org/Web3-Internship-Handbook),
which is also configured locally as the `upstream` Git remote:

```text
https://github.com/ethpanda-org/Web3-Internship-Handbook.git
```

We retain the upstream VuePress + Plume documentation shell, Markdown tooling,
search, Mermaid support, theme structure and GitHub Pages workflow. The current
learner-facing Academy content, navigation and branding are maintained by
Blockchain@NTU and are not the upstream curriculum.

The fork's inherited README and package metadata contain different licensing
signals: MIT for the software/package surface and CC BY-NC-SA 4.0 for educational
material. The original repository does not provide a single unambiguous licence
file in this checkout, so this note does not make a broader legal claim. Preserve
the upstream attribution for any retained or adapted upstream material and review
the original repository's notices before redistribution.

Academy-authored and adapted material is tracked in [SOURCES.md](./SOURCES.md).
The Web3 Internship Handbook is listed there as permission-based reuse where it
informs Academy pages.
