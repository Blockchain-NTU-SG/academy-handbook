## Notes on licences

**MIT OpenCourseWare is Link, not Reuse, by choice.** It is CC BY-NC-SA, and the
ShareAlike term would force any page adapting it onto the same licence. Using it
as further reading avoids that.

**Watch the code/content split.** Both ethereum.org and GitHub Docs license their
site code under MIT and their written content under CC BY 4.0. A repository badge
showing MIT refers to the code, not the articles.

The SMU Blockchain "Lesson 1 — Blockchain Basics" deck was used as a coverage
reference only. No text or image from it is reused here, and no permission is
claimed.

## Academy attribution rule

Every adapted handbook page should retain a Sources and attribution section. The
`Reuse` / `Link` classification is a working content record, not a substitute for
checking the current terms of the linked source or the permission record.
