# Resources

Use this page when you know what you want to learn next. Each link has one
short job; you do not need to read everything in every group.

## Learn the fundamentals

- [Ethereum for developers](https://ethereum.org/developers/) — a structured reference when you want the precise version of an Ethereum concept.
- [Ethereum glossary](https://ethereum.org/glossary/) — a quick definition when a Web3 term is unfamiliar.
- [Bitcoin whitepaper](https://bitcoin.org/bitcoin.pdf) — the original concise explanation of Bitcoin's design; read it after Week 1 if you want more detail on Proof of Work.
- [EIPs](https://eips.ethereum.org/) — Ethereum's public proposal documents when you want to see how technical standards are written and discussed.

## Build and inspect contracts

- [Remix](https://remix.ethereum.org/) — use it to compile, deploy and call a small Solidity contract in a browser.
- [Solidity documentation](https://docs.soliditylang.org/) — use it when you need the exact meaning of a Solidity feature.
- [OpenZeppelin Contracts](https://github.com/OpenZeppelin/openzeppelin-contracts) — inspect widely reused contract building blocks; reuse is not a security guarantee.
- [Scaffold-ETH 2](https://github.com/scaffold-eth/scaffold-eth-2) — explore a fuller local development setup after the Foundation browser lab.
- [SpeedRunEthereum challenges](https://github.com/scaffold-eth/se-2-challenges) — practise by building small Ethereum projects when you want a hands-on extension.

## Explore on-chain activity

- [Etherscan](https://etherscan.io/) — inspect transactions, addresses, contracts and token activity on Ethereum.
- [Dune](https://dune.com/) — query and visualise on-chain data when you want to investigate a question across many transactions.
- [DefiLlama](https://defillama.com/) — compare protocol and sector data, while remembering that metric definitions matter.
- [L2BEAT](https://l2beat.com/) — compare Ethereum Layer 2 systems and their current trust and maturity assumptions.

## Research an industry question

- [The Web3 industry map](../foundation/week-4/part-1-industry-map.md) — start here when you need sector vocabulary and a limitation to investigate.
- [Research tool map](../foundation/week-4/part-3-research-tool-map.md) — choose a source that fits the question and cross-check an important claim.
- [Ethereum DeFi](https://ethereum.org/defi/) — use it for a plain-language overview of decentralised finance.
- [Ethereum NFTs](https://ethereum.org/nft/) — use it when you want the broader idea behind non-fungible tokens and digital ownership.

## Keep security in view

- [Ethereum security](https://ethereum.org/security/) — review common wallet and application safety principles.
- [Revoke.cash](https://revoke.cash/) — inspect and revoke token approvals when you are checking permissions on a supported network.
- [Ethernaut](https://ethernaut.openzeppelin.com/) — practise recognising common smart-contract mistakes in a deliberately guided environment.
