# Resources

The handbook is a learning path, not a link directory. Use each page's Sources
and attribution section for the material that informs it. The repository-wide
reuse, link and avoid classifications are in
[SOURCES.md](https://github.com/Blockchain-NTU-SG/academy-handbook/blob/main/SOURCES.md).

The Education Director's Semester 1 Resource List remains the detailed planning
reference for future page authors. Add a resource to a learner-facing page only
when it has a clear role in that page's Core, Landscape or Further Exploration.
