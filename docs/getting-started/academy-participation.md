# Learn independently or join the Academy

The Handbook is the complete public curriculum. You can follow W0 through W10
independently, whether or not you take part in the organised Blockchain@NTU
Academy experience.

## Independent learning

**Read-only:** Read the full curriculum, inspect its examples and skip hands-on
exercises if you only want the explanations. No account, NTU affiliation or
organised participation is needed.

**Hands-on:** Use the tools named by each task. A GitHub account is needed for
GitHub-specific actions such as pushing work. Independent hands-on learning
does not require WCB, and cloning or running a public repository does not
require a GitHub account. Self-check your work or invite a peer, mentor or
educator to give feedback.

## Blockchain@NTU Academy participation

The organised Academy experience uses the same curriculum. Through Web3 Career
Build (WCB), it can add structured pacing, official task submission and review,
and progress and points tracking. These participation features do not change
the Handbook's lesson content, tasks, completion criteria or project requirements.

### Before you start

You need a GitHub account to sign in to WCB. The Handbook itself is public and
does not require an Academy account. WCB uses GitHub authentication; you do not
need to create a repository for participation sign-in.

### Step 1: Create or confirm a GitHub account

If you already completed the optional GitHub setup in [Week 0](./welcome-and-setup.md),
continue to Step 2. Otherwise, create a free [GitHub account](https://github.com/signup)
and verify your email. Turning on two-factor authentication is strongly
recommended.

### Step 2: Open the Academy page on WCB

Use the [official Blockchain@NTU Academy page on WCB](https://web3career.build/en/programs/blockchain-ntu-academy)
to see participation details and availability.

### Step 3: Sign in with GitHub

Choose the GitHub sign-in option (currently labelled **Continue with GitHub**)
and complete WCB's authorization flow. Review WCB's current terms before
choosing to proceed.

::: tip Expected result
You should return to WCB signed in with your GitHub-linked account.
:::

### Step 4: Check participation availability

Use the WCB page to check organised participation availability. If it shows no
active offering, or the status is unclear, continue with the public W0–W10
Handbook independently. WCB availability does not control access to the
curriculum.

### Step 5: Know which source to use

| Handbook | WCB |
|---|---|
| Canonical lessons, task instructions, completion criteria and project requirements | Organised participation, formal submission and review, progress and points tracking |

If the two ever differ on curriculum requirements, follow the Handbook.
