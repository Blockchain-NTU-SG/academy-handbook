# Foundation

Weeks 1–4 build the shared map that both Deep Dive tracks use. Read them in
order:

| Week | Focus | Anchor Mission |
|---|---|---|
| [Week 1](./week-1/) | Web3, blockchain, crypto assets and wallets | 100 points |
| [Week 2](./week-2/) | Blockchain architectures, Ethereum and interoperability | 100 points |
| [Week 3](./week-3/) | Smart contracts, tokens and DApps | 100 points |
| [Week 4](./week-4/) | Web3 industry, research and contribution | 100 points |

The Foundation is one continuous arc. The current Foundation Pilot ends here
after the Week 4 Anchor Mission. In the full programme, the Week 4 Track
Exploration Card is a provisional choice that leads into Builder or Researcher
Deep Dive; it is not a final Proof of Work commitment.

Each page separates **Core**, **Landscape** and **Further Exploration** so
breadth does not become heavier assessment.
