# Weeks 5–8 — Proof of Work sprint

Members build one small thing they can show. The scope must be buildable by a
beginner in the time available; the most common failure is scoping too large in
Week 5.

The sprint is worth 400 points within the 800-point Semester 1 programme.

| Week | Focus | Output |
|---|---|---|
| [5](./week-5-define.md) | Define | Problem, scope, repo, plan, definition of done |
| [6](./week-6-build.md) | Build V0 | Something reviewable |
| [7](./week-7-review.md) | Review and improve | Peer review, validated assumptions, documented limits |
| [8](./week-8-ship.md) | Ship | Final output, README, demo, AI disclosure, next steps |

Directions are starting points, not restrictions. What is judged is the quality
of the Proof of Work, not category discipline.
