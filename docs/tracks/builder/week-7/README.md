# Builder Week 7 — Reliable Web3 Engineering

Test the behaviour built in W5–W6, locate failures with evidence, and reason
about security assumptions before they become incidents.

Each Part has one reviewable task worth **100 points**. There is no separate
weekly submission.

| Part | Title | Estimated total | Task status |
|---:|---|---|---|
| 1 | [Testing Contract Behaviour](./part-1-testing-contract-behaviour.md) | 40 min hands-on | Drafting |
| 2 | [Simulation, Debugging and Tracing](./part-2-simulation-debugging-and-tracing.md) | 50 min hands-on | Drafting |
| 3 | [Security Engineering](./part-3-security-engineering.md) | 45 min hands-on | Drafting |

**Required estimate: 135 minutes (2 h 15 min).** These are approximate learner-time estimates, not deadlines; revise them as learner evidence improves. Optional exploration is outside the estimate.

**Assessment:** 3 Part tasks × 100 points = **300 points** in the Academy progression. Academy participants submit each Part for a **Complete** or **Revise** review. Independent readers may use the criteria to self-check without formal point tracking. There are no partial scores.
