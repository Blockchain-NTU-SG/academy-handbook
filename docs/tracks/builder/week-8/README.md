# Builder Week 8 — Integration, Shipping and Independence

Use unfamiliar protocol documentation to integrate a bounded feature, make
deployment reproducible, then demonstrate that you can enter a new
specification and build independently.

Each Part has one reviewable task worth **100 points**. There is no separate
weekly submission.

| Part | Title | Estimated total | Task status |
|---:|---|---|---|
| 1 | [Docs-Driven Integration](./part-1-docs-driven-integration.md) | 60 min hands-on | Drafting |
| 2 | [Deployment and Reproducibility](./part-2-deployment-and-reproducibility.md) | 75 min hands-on | Drafting |
| 3 | [Independent Builder Challenge](./part-3-independent-builder-challenge.md) | 120 min hands-on | Drafting |

**Required estimate: 255 minutes (4 h 15 min).** These are approximate learner-time estimates, not deadlines; revise them as learner evidence improves. Optional exploration is outside the estimate.

**Assessment:** 3 Part tasks × 100 points = **300 points**. Completion is
binary: use the Part completion criteria to self-check. Complete earns 100 points; otherwise revise incomplete or materially incorrect work. There are no partial scores.
