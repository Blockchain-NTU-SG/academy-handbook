# Builder Deep Dive

Builder learners develop the transferable skill of **composing unfamiliar Web3
systems**: turning a clear behaviour into contracts, programmatic interactions,
interfaces and reliable evidence.

This Deep Dive begins after Foundation's Solidity, Remix, ABI and RPC
introduction. It is not another smart-contract introduction.

## Weeks

- [Week 5 · Programmatic Web3 Development](./week-5/)
- [Week 6 · Reliable Web3 Engineering](./week-6/)

Each week contains six Part tasks. Every Part task is worth **100 points** and
is assessed by completion and understanding, with revision when the work is
incomplete or materially incorrect.

> **Status: scaffold.** The Education team will author the detailed lessons,
> examples and task instructions.
