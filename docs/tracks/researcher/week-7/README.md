# Researcher Week 7 — On-Chain Evidence and Measurement

Check system claims against chain records, trace fund movement without
overclaiming identity, and measure a bounded public data series reproducibly.

Each Part has one reviewable task worth **100 points**. Core tools are free and
need no account; optional industry-data paths may require separate access.
There is no separate weekly submission.

binary: use the Part completion criteria to self-check. Complete earns 100 points; otherwise revise incomplete or materially incorrect work. There are no partial scores.
