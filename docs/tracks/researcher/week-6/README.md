# Researcher Week 6 — Measure and Verify Blockchain Systems

Week 5 taught you to take a system apart on paper. This week checks that
picture against reality: you trace one transaction, query 90 days of real
activity, decide what a fair measurement looks like, test a token's market,
follow a failure through its dependencies, and finish with a short brief that
argues against itself.

Each Part has one lightweight, reviewable hands-on task worth **100 points**.
Every tool used is free and needs no account: block explorers, DefiLlama's
public API, a short Python script, DuckDB in the browser and a spreadsheet.

**There is no separate weekly submission.** These six Part tasks are the
assessed progress evidence for this week.
