# Proof of Work

Proof of Work begins after the Builder or Researcher Deep Dive. It is the
reviewable project layer of the full Academy, not a single four-week sprint
that starts immediately after Foundation.

::: important In development for Cohort 1 · January 2027
The September–October 2026 Foundation Pilot ends after Week 4. The full Cohort 1
programme continues through Deep Dive, Scope Freeze and these W7–W8 milestones.
:::

| Stage | Purpose | Points |
|---|---|---:|
| [Scope Freeze](./scope-freeze.md) · end of W6 | Freeze a realistic Builder or Researcher project scope | 100 |
| [W7 · MVP / V1](./week-7-mvp.md) | Produce the smallest meaningful version | 100 |
| [W8 · Final PoW](./week-8-final.md) | Ship a reviewable final artefact | 200 |

The exact task requirements will be authored by the Education team. The
reviewer model remains completion-based: work is completed or returned for
revision, without fractional rubric scores.
