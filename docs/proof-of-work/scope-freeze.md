# PoW Scope Freeze — end of Week 6

After the Deep Dive, the learner freezes a realistic Proof of Work scope. This
is a shared checkpoint with Builder and Researcher paths; detailed instructions
are in development for the Education team.

| Builder scope should eventually cover | Researcher scope should eventually cover |
|---|---|
| problem / user | research question |
| why blockchain | why it matters |
| core flow and architecture | initial hypothesis or view |
| biggest technical unknown | scope and primary sources |
| core deliverable and out of scope | data/evidence sources and planned analysis |
| definition of done | biggest uncertainty, final deliverable and definition of done |

**Assessment:** one completed scope checkpoint = **100 points**. It is not a
final project submission; it is the decision gate that makes W7 and W8
reviewable.
